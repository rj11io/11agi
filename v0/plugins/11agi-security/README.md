# 11agi Security

A reserved home for security skills that go beyond dependency scanning: threat
modeling, secure-coding review, and secrets handling.

## Skills

| Skill | Use it for |
| --- | --- |
| [`11agi-security-placeholder`](./skills/11agi-security-placeholder/SKILL.md) | Explaining what this plugin will hold, and pointing you to `11agi-audit` for the security checks that run today |

## Status

This plugin has one skill, and it is a placeholder. No scan, check, or report
runs from here yet. For security work that runs today, use the
[`11agi-audit`](../11agi-audit/README.md) plugin: it audits dependencies for
vulnerabilities and malware, and audits this repository's own marketplace and
plugin configuration files.
